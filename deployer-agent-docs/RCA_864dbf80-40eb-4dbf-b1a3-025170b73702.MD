### Deployment secret mechanism (your (a)/(b) question)
Nuanced — depends on key class:
- **Custom / user keys** (your own API keys, webhook secrets like `RESEND_WEBHOOK_SECRET`, `TWILIO_WEBHOOK_VALIDATION`, `SESSIONS_VALID_AFTER`): YES to both — carried forward from the previous PRODUCTION run; the preview `.env` only **ADDS** keys prod lacks and **never overwrites or deletes** a key already set in prod.
- **System / platform keys**: NO — these are **regenerated and overwritten on EVERY deploy**: `MONGO_URL`, `DB_NAME`, `REACT_APP_BACKEND_URL`, `INTEGRATION_PROXY_URL`, **all `STRIPE_*` keys**, `EMERGENT_PUSH_KEY`. Any value containing a preview URL is rewritten to the prod URL.
- ⚠️ **Direct impact on your webhook hotfix:** `STRIPE_WEBHOOK_SECRET` and `STRIPE_BILLING_WEBHOOK_SECRET` match the `STRIPE_*` system pattern, so they are platform-managed and may be overwritten each deploy — pinning them via the Secrets tab is not guaranteed to stick. `TWILIO_WEBHOOK_VALIDATION` and `RESEND_WEBHOOK_SECRET` are custom and WILL persist once you set them in prod.
