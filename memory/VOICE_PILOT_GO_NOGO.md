# Founder Voice Pilot: GO / NO-GO for a real iPhone pilot (Oct 13 2026)

**Verdict: GO for a founder-only pilot on the founder's own account. NO-GO for any other person or account.**
Nothing has been deployed, no EAS update published, no production account enrolled. Preview is the only place the code runs.

## 1. What the pilot build does
- Limits apply ONLY to accounts whose `voice_policies` row has `enabled: true`. Every production account is un-enrolled (the collection does not exist in production yet), so behaviour is byte-for-byte today's: super admins unlimited, reps on the legacy 900 s cap, `GET /api/live-voice/config` returns `controls: null`. The only change for everyone: one `policy_mode: legacy` ledger row per conversation (read-only accounting). Covered by `test_voice_controls` "non-enrolled unchanged" and `test_voice_pilot::test_leave_returns_to_legacy`.
- Voice Pilot screen (More > Internal Operations > Voice Pilot, `/admin/voice-pilot`, owner-only tile; super admin API `/api/voice-controls/pilot*`): enrol MY account only (2 min GPT-Live + 10 min Realtime Mini per user per day, $20/month hard cap on both engines, super admins capped like everyone), status (policy, safety flags, other enrolled accounts, env: OpenAI configured / fake provider / build), today's pools, month spend vs cap, open sessions, hand-offs, recent segments, kill switch (refuses new sessions + hangs up and finalizes every open one), resume, leave (back to legacy; usage and ledger kept).
- Cost at the pilot limits: GPT-Live $0.05/min x 2 = $0.10/day, Mini ~ $0.015/min x 10 = $0.15/day (token-based estimate when the app reports usage). Worst case ~$0.25/day, so the $20 cap would only bind after ~80 days: see test D for how to watch it bind without spending $20.

## 4. Deploy sequence (only when you say GO; nothing below has been done)
1. **Save to GitHub** (this step's checkpoint).
2. **Deploy.** When the pod is up: `curl -s https://app.imonsocial.com/api/health` -> `"build": "2026-10-13.voice-pilot"`; `curl -s -o /dev/null -w "%{http_code}" https://app.imonsocial.com/api/voice-controls/pilot` -> `401` (route live, auth required). At this point nothing is enrolled: production behaves exactly as before for everyone, including you. Safe place to stop.
3. **Mac:** `grep EXPO_PUBLIC_BACKEND_URL frontend/.env` must print `https://app.imonsocial.com`, then `cd frontend && git pull && yarn install && eas update --branch production --message "$(git log -1 --pretty=%s)"`.
4. **iPhone:** force-quit the app, open it, wait ~10 s, force-quit and open again (the OTA applies on the second launch). Proof of the new bundle: More > Internal Operations shows **Voice Pilot** (needs the owner flag: if the Founder Command Center tile is missing too, production `OWNER_EMAIL` is not `forest@imonsocial.com`; fix the secret first).
5. **Enrol:** Voice Pilot > "Enrol my account only" (2 / 10 / 20 prefilled). Status card must read: State **Enrolled**, Other accounts enrolled **0**, Super admins capped **Yes**, Fake provider **off**, OpenAI **configured**, Build **2026-10-13.voice-pilot**. Anything else: tap **Leave pilot** and stop.

## 5. iPhone test script (about 10 minutes, under $0.50 in total)
**A. Model transition (~3 min, ~$0.15).** Home > Talk to Jessi. Header "Listening · Gleam". Talk about anything for 2 minutes. Expected: with < 60 s left the cap line reads "Under a minute left today"; at 2:00 a 1-2 s pause, then the note "Switched to Jessi's standard voice", header "Marin · mini", Jessi continues the same topic WITHOUT greeting again, captions stay, the timer keeps counting. Talk 30 s more, End. Voice Pilot (pull to refresh): Hand-offs 1 row (live -> mini, reason `premium_cap`), Recent 2 segments, Today premium used ~120 s, My allowance premium 0 left, next engine mini.
FAIL signs: "Could not switch the voice line" (`handoff_failed`); a segment with stop reason `server_kill` or `kill_attempts` > 0 (the app ignored the stop); `stale_meter`; an `unconfirmed` segment.
**B. Second conversation the same day** starts on Mini straight away (note shown from the start, header mini).
**C. Kill switch (~1 min).** Start a conversation on the phone; on the Mac open https://app.imonsocial.com/admin/voice-pilot as you and tap **Kill switch**. Within one heartbeat (~6 s) the phone ends with "Paused by the account owner", the Talk to Jessi card reads "Live Jessi is paused", Active sessions = 0, the segment's stop reason is `killed`. Tap **Resume**; talking works again. (Same phone also works: shrink the sheet to the Jessi pill, go to Voice Pilot, Kill.)
**D. Spending cap (~1 min, pennies).** Voice Pilot > PILOT LIMITS: set the monthly cap to "Spent this month" + $0.02 (e.g. 0.17 -> 0.19) > Save limits. Expected: "Limits in play" shows `account_hard_cap`, premium left 0, backup left ~ 80 s. Start a conversation: Mini only, it ends by itself at that many seconds with "Today's voice minutes are used up" and the gold **Ask Jessi by text** button; tap Talk again -> refused (Home card "Live Jessi is resting", server 429). Pilot screen: Cap left $0.00, next engine none. Set the cap back to 20 > Save limits -> next engine mini again. This is the server-side hard cap doing its job; at pilot limits the $20 would otherwise take ~80 days to reach.
**E. Optional: exhaust Mini (~10 min, under $0.40).** Talk until "Today's voice minutes are used up"; the Home card then says Live Jessi is resting until the reset time. Resets at midnight in the account's time zone.
**F. Afterwards:** keep the account enrolled for a week and glance at Voice Pilot daily, or tap **Leave pilot** (back to legacy, usage and ledger kept).

## 6. NO-GO triggers during the pilot
Fake provider on in production; Other accounts enrolled > 0; any `handoff_failed`; `server_kill` / `stale_meter` / `unconfirmed` rows; month spend rising faster than the minutes explain (Mini token reports); any change noticed on another account (there is no path for one, but that is the point of a pilot).
